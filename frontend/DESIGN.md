# Overpass visual system
The user has requested a modern Google Earth style workspace: Operate mode, full-window map, quiet floating controls, and information on demand. The map is the primary working surface. No permanent statistics rail or information card grid.
The map retains its original space-black surface, blue geography, aqua VIIRS marks, violet MODIS marks, yellow selected outlines, gradient overlay, and camera composition. The surrounding interface uses shadcn/ui slate tokens, neutral primary controls, consistent borders, visible focus states, accessible popovers and sheets, and Lucide icons. Typography retains Public Sans and DM Mono, with system fallbacks.
First viewport: the geographic map fills the screen. A small brand, district search, tool dock, camera controls, and compact playback timeline float above it. Only the current area and period are shown as map context. Explore districts, Layers, Satellites, and Evidence are opened explicitly; year and playback speed are in a date popover. Import, refresh, export, theme, and help share one settings menu. Mobile retains the full map and uses compact panels, without a scrolling stack of cards.
Fleet experiments are in the Satellites panel. Grounding changes the actual loaded record and satellite status; adjusted uncertainty and retention depend on supplied model outputs. An active simulation is marked on the map, with the comparison available in the panel.
The map uses OpenFreeMap geography and real geoBoundaries district polygons. It plots actual loaded observations and district columns. Raw counts use log(1 + count); calibrated columns use imported lower bounds and uncertainty caps. Clouds are not fabricated from detection counts. The calendar and evidence table remain available when WebGL fails. Mobile keeps all controls and data accessible.
